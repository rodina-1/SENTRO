# SENTRO
## Trust-Aware Autonomous Irrigation System

### Project Overview
SENTRO is an intelligent irrigation system that integrates AI, IoT, Robotics, and Cybersecurity to provide secure and reliable autonomous irrigation.

### Main Objectives
- Monitor soil and environmental conditions.
- Enable intelligent irrigation decisions.
- Detect abnormal behavior and potential cyberattacks.
- Protect communication between system components.
- Ensure safe and reliable irrigation operations.

### Main Domains
- Artificial Intelligence
- Internet of Things
- Robotics
- Cybersecurity
- Cloud Computing
